# AI 创作全能课｜片头交接项目

本仓库只包含约 60 秒课程片头的交接资料，不包含正式 12 节课程文档。

**第十二版已被用户否定：不好看、节奏乱。它是诊断材料，不是已通过的方案。当前授权是资料交接，不包含继续收费生成。**

## 从这里接手

1. 先读 [交接文档](handoff/HANDOFF.md)，了解剧情、已确认台词、输入规则、失败原因和预算状态。
2. 看 `references/` 里的两条参考片，听 `outputs/片头第八版_音乐试听/试听音乐/03_Mureka_电子追逐_60秒试听.mp3`。
3. 查看 [第十一版完整脚本](handoff/第十一版脚本_完整可读副本.md) 与静帧动态分镜。
4. 对照两条第十二版生成原片和剪辑版，读 [实际剪辑改动](handoff/第十二版实际剪辑对照.md)。
5. 重新梳理节奏与转场，按用户新的指令推进。不能机械继承第十二版剪辑。

## 下载与播放

仓库已包含图、视频和声音文件，不依赖原作者电脑路径，不需要另装 Git LFS。

- GitHub 页面选择 **Code → Download ZIP**，完整解压；或用已获授权的 GitHub 账号克隆。
- 在本地打开 `outputs/片头第十一版_动态分镜/打开看_第十一版动态分镜对照.html`。
- 在本地打开 `outputs/片头第十二版_双30秒480P/打开看_第十二版60秒剪辑预览.html`。
- GitHub 网页不会直接运行这些 HTML，需下载后打开；图文分镜图片、音频、视频已一并打包。
